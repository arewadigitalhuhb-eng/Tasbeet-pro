# 📿 Tasbeeh Pro — Digital Dhikr Companion

A modern, professional digital tasbeeh counter built with vanilla HTML, CSS, and JavaScript.

## ✨ Features

- 🎨 Modern UI with Dark/Light themes
- 🌐 Multi-Language: English, Arabic (RTL), Hausa
- 📿 13 Dhikr presets with categories
- 📊 Statistics with weekly charts
- 🔊 Audio feedback (Digital / Beads / Silent)
- 📳 Haptic feedback
- 🎯 Custom targets
- 💾 Session saving
- 📤 Export/Import JSON
- 🔒 Keep Screen On
- ⌨️ Keyboard shortcuts
- 📱 PWA Ready (offline)

## 🚀 Quick Start

1. Create folder `tasbeeh-pro/`
2. Create subfolders `css/` and `js/`
3. Copy each file to its location
4. Open `index.html` in browser

## ⌨️ Shortcuts

| Key | Action |
|-----|--------|
| Space / Enter | Count +1 |
| R | Reset |
| U | Undo |
